# Python-Mini-Project
#To-Do List Application

### 📝 Organize Your Day, One Task at a Time!

## 📌 1. Project Overview

TaskFlow is a simple and user-friendly To-Do List Application developed using Python. It helps users manage their daily tasks efficiently through a graphical user interface (GUI).

The application allows users to add tasks, mark them as completed, delete tasks, and save their tasks for future use. It uses Python's built-in Tkinter library to create the interface and file handling to store task information.

## 🎯 2. Project Objectives

* 📚 Understand and implement Python lists.
* ⚙️ Use functions to perform different operations.
* 💾 Implement file handling to store and retrieve tasks.
* 🖥️ Develop a graphical user interface using Tkinter.
* ✅ Create a simple application for daily task management.

## 🛠️ 3. Technologies Used

| Technology            | Purpose                   |

| 🐍 Python             | Core programming language |
| 🖥️ Tkinter           | Graphical User Interface  |
| 📂 JSON File Handling | Store and retrieve tasks  |
| 💻 Visual Studio Code | Code editor               |

## ✨ 4. Features

* ➕ **Add Tasks:** Add new tasks using the input field.
* 📋 **View Tasks:** Display all saved tasks in a list.
* ✅ **Complete Tasks:** Mark tasks as completed or pending.
* 🗑️ **Delete Tasks:** Remove unwanted tasks.
* 💾 **Automatic Saving:** Save tasks automatically in a local file.
* 🔄 **Load Saved Tasks:** Retrieve previously saved tasks when the application starts.
* 📊 **Task Statistics:** Display total, completed, and pending tasks.
* 🎨 **Attractive GUI:** Enjoy a simple and user-friendly interface.

## 🧠 5. Python Concepts Used

### 📋 Lists

A Python list stores all tasks and allows the application to add, access, update, and remove tasks.

### ⚙️ Functions

Functions such as `add_task()`, `delete_task()`, `complete_task()`, and `display_tasks()` perform specific operations.

### 💾 File Handling

The application saves tasks in `tasks.json` and loads them when the program starts.

### 🖥️ GUI (Graphical User Interface)

The Tkinter library creates the application window, buttons, input field, task list, and other graphical elements.

## ⚙️ 7. Requirements

* 🐍 Python installed on your computer.

## 🚀 8. How to Run the Project

1. 🐍 Install Python on your computer.

2. 💻 Open Visual Studio Code.

3. 📂 Open the `TodoListProject` folder.

4. ⌨️ Open the terminal in VS Code.

5. ▶️ Run the following command:

   ```bash
   python todo.py
   ```

6. 🖥️ The TaskFlow application will open in a separate window.

7. ✍️ Enter a task and click **Add Task**.

8. ✅ Select a task to mark it as completed or pending.

9. 🗑️ Delete tasks whenever required.

## 🔄 9. How the Application Works

1. ✍️ The user enters a task in the input field.
2. 📋 The application stores the task in a Python list.
3. 🖥️ The task appears in the GUI.
4. 💾 File handling saves the tasks in a JSON file.
5. 🔄 Previously saved tasks are loaded when the application restarts.
6. ✅ Users can mark tasks as completed or pending.
7. 📊 Task statistics update automatically.
